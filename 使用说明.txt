==========================================
MQTT Monitor 使用说明
==========================================

本软件是一个功能强大的 MQTT 监控和管理工具，支持实时数据可视化、历史数据查询、
智能告警监测、命令发送和完整的日志记录功能。

==========================================
一、主界面布局
==========================================

1. 顶部菜单栏
   ■ 文件菜单
     • MQTT 连接设置：配置 MQTT 服务器连接参数（支持 TLS/SSL）
     • 图表设置：配置图表显示参数和刷新间隔
     • 退出：关闭应用程序

   ■ 数据监控菜单（⭐ 新功能）
     • 历史数据查询：查询和导出历史 CSV 数据
     • 历史告警查询：查询历史告警记录和统计信息
     • 告警配置：配置各设备测点的告警规则
     • 提醒设置：配置告警提醒方式（声音、视觉等）

   ■ 帮助菜单
     • 使用说明：打开本说明文档
     • 联系我们：查看公司联系方式

2. 功能标签页（中央显示区域）
   ■ 图表视图：实时数据可视化图表，支持多条曲线和图例管理
   ■ 表格视图：表格形式展示接收到的数据
   ■ 命令发送：向 MQTT 设备发送预配置的命令
   ■ 告警：显示当前活动告警和告警统计信息
   ■ 日志：系统运行日志和事件记录

3. 右侧主题订阅区域
   • 订阅的主题列表：显示当前已订阅的所有 MQTT 主题
   • 新主题订阅：输入框添加新的订阅主题（支持通配符）
   • 订阅按钮：点击订阅新主题
   • 取消订阅：右键点击主题选择取消订阅

4. 底部状态栏
   • 连接状态：实时显示当前 MQTT 连接状态
   • 连接按钮：快速连接到 MQTT 服务器
   • 断开按钮：断开当前 MQTT 连接

==========================================
二、MQTT 连接设置
==========================================

通过 [文件] -> [MQTT 连接设置] 打开配置窗口

1. 基础连接配置
   ■ 服务器地址：MQTT 服务器的 IP 地址或域名
     示例：192.168.1.100 或 mqtt.example.com

   ■ 端口：MQTT 服务器端口
     • 默认端口：1883（未加密）
     • TLS 端口：8883（加密连接）

   ■ 用户名：MQTT 服务器认证用户名（可选）

   ■ 密码：MQTT 服务器认证密码（可选）
     注意：密码会自动加密保存在配置文件中

   ■ 客户端ID：MQTT 客户端唯一标识
     提示：留空会自动生成随机 ID

   ■ 基础 Topic：用于命令发送和响应的基础主题前缀

2. TLS/SSL 加密配置
   ■ 启用 TLS/SSL 加密连接：勾选后使用加密连接

   ■ CA 证书路径：用于验证服务器身份的根证书文件（单向 TLS）
     文件格式：.crt, .pem

   ■ 客户端证书路径：客户端身份证书（双向认证时使用）
     场景：AWS IoT, Azure IoT 等云平台

   ■ 客户端私钥路径：客户端私钥文件（双向认证时使用）

   ■ 忽略证书错误：仅用于测试环境，生产环境不推荐

   使用场景说明：
   • 自托管 Mosquitto（单向 TLS）：只需填写 CA 证书路径
   • AWS IoT/Azure IoT（双向 TLS）：需要 CA 证书 + 客户端证书 + 私钥
   • 开发测试环境：可勾选"忽略证书错误"快速测试

==========================================
三、图表视图
==========================================

图表页面提供强大的实时数据可视化功能。

1. 主要功能
   ■ 实时曲线图：自动绘制 MQTT 消息中的数值数据
   ■ 多条曲线：支持同时显示多个设备、多个参数
   ■ 图例管理：点击图例项可显示/隐藏对应曲线
   ■ 自定义颜色：可为每条曲线自定义显示颜色
   ■ 数据偏移：支持为曲线添加偏移量，便于区分相似数据
   ■ 自动刷新：根据设置的间隔自动更新图表
   ■ 鼠标跟踪：鼠标悬停显示具体数据点的时间和数值

2. 图表设置（通过 [文件] -> [图表设置]）
   ■ 图表最大数据点数量：
     • 默认值：1000 点
     • 说明：控制图表显示的历史数据量
     • 建议：根据性能需求调整（100-5000）

   ■ 图表更新间隔：
     • 默认值：800 毫秒
     • 说明：控制图表刷新频率
     • 建议：500-2000ms，越小越流畅但占用更多 CPU

3. 图例右键菜单
   • 自定义颜色：更改曲线显示颜色
   • 设置偏移量：为曲线添加垂直偏移
   • 隐藏/显示：临时隐藏或显示曲线

==========================================
四、表格视图
==========================================

表格页面以表格形式展示接收到的 MQTT 数据。

1. 主要功能
   ■ 数据列表：按时间倒序显示所有接收的消息
   ■ 自动解析：自动解析 JSON 格式的 MQTT 消息
   ■ 动态列：根据数据字段自动创建表格列
   ■ 排序功能：点击列头对数据进行排序
   ■ 自动导出：所有数据自动保存为 CSV 文件

2. 数据导出
   ■ CSV 文件位置：
     • 目录：程序根目录下的 data 文件夹
     • 文件名格式：data_YYYYMMDD.csv（按天存储）
     • 示例：data/data_20250110.csv

   ■ CSV 文件特点：
     • 批量写入优化，提高性能
     • 每 5 秒或 100 条记录自动刷新
     • 可用 Excel 或其他工具直接打开
     • UTF-8 编码，支持中文

==========================================
五、命令发送
==========================================

命令页面用于向 MQTT 设备发送预配置的命令。

1. 主要功能
   ■ 命令选择：从下拉框选择预配置的命令模板
   ■ 参数输入：根据命令定义，填写所需参数
   ■ 发送命令：验证参数后发送到 MQTT 服务器
   ■ 命令历史：显示已发送的命令历史记录

2. 命令配置文件
   ■ 文件位置：
     • 文件名：commands.json
     • 目录：程序根目录下的 configs 文件夹
     • 完整路径：configs/commands.json

   ■ 配置文件格式（JSON 数组）：
   [
     {
       "commandName": "设置温度",
       "description": "设置设备目标温度",
       "topic": "device/control/temperature",
       "parameters": [
         {
           "name": "temperature",
           "displayName": "温度值",
           "type": "number",
           "defaultValue": "25"
         },
         {
           "name": "deviceId",
           "displayName": "设备ID",
           "type": "string",
           "defaultValue": "device001"
         }
       ]
     }
   ]

   ■ 参数说明：
     • commandName：命令名称（显示在下拉框中）
     • description：命令描述
     • topic：发送命令的 MQTT 主题
     • parameters：命令参数数组
       - name：参数名称（JSON 字段名）
       - displayName：参数显示名称
       - type：参数类型（number, string, boolean）
       - defaultValue：默认值

==========================================
六、告警功能 ⭐ 新功能
==========================================

智能告警系统可以实时监测设备数据，超限时自动触发告警。

1. 告警页面
   ■ 活动告警：
     • 显示当前所有未恢复的告警
     • 红色高亮显示告警设备和参数
     • 支持确认告警操作

   ■ 告警统计：
     • 今日告警总数
     • 活动告警数量
     • 已确认告警数量
     • 告警排名（按设备/测点统计）

2. 告警配置（通过 [数据监控] -> [告警配置]）
   ■ 左侧设备树：
     • 显示所有接收数据的设备和测点
     • ⚠️ 图标表示该测点已启用告警
     • 点击测点可配置告警参数

   ■ 右侧配置面板：
     • 启用告警：总开关，勾选后该测点启用告警检测

     • 上限告警：
       - 启用上限告警：勾选启用
       - 上限值：设置告警阈值

     • 下限告警：
       - 启用下限告警：勾选启用
       - 下限值：设置告警阈值

     • 持续时长：
       - 说明：避免瞬时波动触发告警
       - 设置：数值超限持续N秒后才触发告警
       - 建议：3-10 秒

     • 通知方式：
       - 视觉提醒：表格变红+闪烁效果
       - 声音提醒：播放告警音效
       - 重复间隔：告警音重复播放间隔（分钟）

   ■ 快捷操作：
     • 全部启用：一键启用所有测点的告警
     • 全部禁用：一键禁用所有测点的告警

3. 提醒设置（通过 [数据监控] -> [提醒设置]）
   ■ 声音提醒：
     • 启用声音提醒：总开关
     • 告警音文件：Sounds/alarm.wav
     • 恢复音文件：Sounds/recovery.wav
     注意：可自定义音频文件（WAV 格式）

   ■ 视觉提醒：
     • 表格闪烁：告警时表格行闪烁
     • 颜色高亮：告警行显示为红色背景

七、历史数据查询 ⭐ 新功能
==========================================

查询和导出历史 CSV 数据记录。

1. 历史数据查询（通过 [数据监控] -> [历史数据查询]）
   ■ 查询条件：
     • 选择设备：从下拉框选择要查询的设备
     • 开始日期：查询起始日期
     • 结束日期：查询结束日期

   ■ 查询结果：
     • 表格显示：查询结果以表格形式展示
     • 数据详情：包含时间戳、设备ID和所有参数值
     • 排序功能：点击列头可排序

   ■ 导出功能：
     • 导出 CSV：将查询结果导出为 CSV 文件
     • 文件命名：自动按设备ID和日期范围命名
     • 保存位置：用户选择保存位置

2. 历史告警查询（通过 [数据监控] -> [历史告警查询]）
   ■ 查询条件：
     • 开始日期：查询起始日期
     • 结束日期：查询结束日期
     • 告警状态：全部/活动/已恢复/已确认

   ■ 查询结果：
     • 告警列表：显示所有符合条件的历史告警
     • 告警详情：设备ID、参数名、告警值、时间等
     • 状态显示：不同颜色区分告警状态

   ■ 导出功能：
     • 导出告警记录：导出为 CSV 文件
     • 统计信息：包含告警次数、持续时间等

==========================================
八、日志页面
==========================================

日志页面记录系统运行的所有事件和错误信息。

1. 主要功能
   ■ 实时日志：
     • 自动滚动显示最新日志（类似 tail -f）
     • 按时间戳排序
     • 不同级别用不同颜色区分

   ■ 日志级别：
     • INFO（蓝色）：普通信息
     • WARNING（橙色）：警告信息
     • ERROR（红色）：错误信息

   ■ 操作功能：
     • 文本复制：选中日志文本可直接复制
     • 字体缩放：Ctrl + 鼠标滚轮调整字体大小
     • 自动保存：日志自动按天保存到文件

2. 日志文件
   ■ 文件位置：
     • 目录：程序根目录下的 logs 文件夹
     • 文件名格式：log_YYYY-MM-DD.txt
     • 示例：logs/log_2025-01-10.txt

   ■ 快捷键：
     • Ctrl + 滚轮向上：放大字体
     • Ctrl + 滚轮向下：缩小字体

==========================================
九、主题订阅管理
==========================================

主题订阅区域位于主界面右侧。

1. 订阅新主题
   ① 在"订阅新 Topic"输入框中输入 MQTT 主题
   ② 点击"订阅"按钮
   ③ 订阅成功后主题会出现在上方列表中

2. 取消订阅
   ① 在已订阅列表中找到要取消的主题
   ② 右键点击主题
   ③ 选择"取消订阅"

3. 主题格式示例
   ■ 基础主题：
     • sensor/temperature（单层主题）
     • device/sensor/temperature（多层主题）

   ■ 通配符主题：
     • sensor/+/temperature（+ 匹配一层）
       示例：匹配 sensor/device1/temperature 和 sensor/device2/temperature

     • sensor/#（# 匹配所有子主题）
       示例：匹配 sensor/temperature、sensor/humidity、sensor/device1/pressure 等

4. 注意事项
   • 订阅的主题会自动保存到配置文件
   • 重启程序后会自动重新订阅
   • 必须先连接 MQTT 服务器才能订阅主题
   • 订阅的主题保存在 configs/mqtt_config.json 文件中

==========================================
十、数据流程说明
==========================================

1. 连接流程
   配置连接参数 → 点击连接 → 建立 MQTT 连接 → 自动订阅保存的主题

2. 数据接收流程
   MQTT 服务器 → 订阅的主题 → 数据解析（JSON） → 更新图表/表格 →
   告警检测 → 保存到 CSV → 记录到日志

3. 告警触发流程
   数据接收 → 告警规则匹配 → 超限持续时长检测 → 触发告警 →
   视觉提醒（表格变红） → 声音提醒 → 记录到告警数据库

4. 命令发送流程
   选择命令 → 填写参数 → 参数验证 → MQTT 发布 → 记录历史 → 记录到日志

==========================================
十一、配置文件说明
==========================================

所有配置文件位于 configs 目录下，采用模块化设计。

1. configs/mqtt_config.json
   • 内容：MQTT 连接配置、订阅主题列表
   • 密码加密：密码字段自动加密（ENCRYPTED: 开头）

2. configs/chart_config.json
   • 内容：图表显示配置
   • 参数：最大数据点数量、更新间隔

3. configs/chart_legend_config.json
   • 内容：图例自定义配置
   • 参数：曲线颜色、偏移量

4. configs/layout_settings.json
   • 内容：窗口布局和位置
   • 参数：窗口大小、位置、状态

5. configs/alarm_config.json
   • 内容：告警规则配置
   • 参数：各测点的上下限、持续时长、通知方式

6. configs/alert_settings.json
   • 内容：告警提醒全局设置
   • 参数：声音开关、视觉效果开关

7. configs/commands.json
   • 内容：命令模板配置
   • 格式：JSON 数组，可手动编辑添加新命令

8. configs/company_info.json
   • 内容：公司联系信息
   • 参数：公司名称、地址、电话、邮箱

9. data 目录
   • 内容：每日 CSV 数据文件
   • 格式：data_YYYYMMDD.csv
   • 特点：批量写入优化，每 5 秒或 100 条自动刷新

10. data/alarm_records.db
    • 内容：告警记录数据库（SQLite）
    • 用途：存储所有历史告警记录

11. data/alarm_history.db
    • 内容：告警历史存储数据库（SQLite）
    • 用途：历史告警查询功能

12. logs 目录
    • 内容：每日日志文件
    • 格式：log_YYYY-MM-DD.txt
    • 编码：UTF-8

13. Sounds 目录
    • 内容：告警音效文件
    • 文件：alarm.wav（告警音）、recovery.wav（恢复音）
    • 说明：可替换为自定义 WAV 格式音频

十二、故障排查
==========================================

1. 无法连接 MQTT 服务器
   ■ 检查项：
     • 服务器地址和端口是否正确
     • 网络连接是否正常（ping 服务器）
     • 用户名密码是否正确
     • TLS 设置是否正确
     • 证书文件路径是否存在
     • 防火墙是否阻止连接

   ■ 排查步骤：
     ① 查看日志页面的详细错误信息
     ② 尝试使用 MQTT 客户端工具（如 MQTT.fx）测试连接
     ③ 如果使用 TLS，验证证书文件是否有效

2. 订阅主题失败
   ■ 检查项：
     • 确保已连接到 MQTT 服务器
     • 主题格式是否正确（不能包含空格）
     • 是否有权限订阅该主题
     • 主题是否存在

   ■ 排查步骤：
     ① 查看日志页面的错误信息
     ② 检查 MQTT 服务器的 ACL 配置
     ③ 尝试订阅通配符主题（如 test/#）测试

3. 数据不显示
   ■ 检查项：
     • 确认主题已成功订阅（右侧列表中显示）
     • MQTT 消息格式必须为 JSON
     • JSON 数据必须包含数值字段
     • 检查数据字段名称

   ■ 排查步骤：
     ① 查看日志确认是否收到数据
     ② 检查 JSON 格式是否正确
     ③ 确认 deviceId 字段是否存在

4. 告警不触发
   ■ 检查项：
     • 确认告警已启用（测点名称后有 ⚠️ 图标）
     • 检查上下限值是否设置正确
     • 确认持续时长设置是否合理
     • 检查数据是否真的超限

   ■ 排查步骤：
     ① 查看告警配置是否保存成功
     ② 查看日志页面是否有告警检测日志
     ③ 检查 configs/alarm_config.json 文件内容

5. 命令发送失败
   ■ 检查项：
     • 确保已连接到 MQTT 服务器
     • 命令参数是否填写完整
     • 参数格式是否正确
     • Topic 是否正确

   ■ 排查步骤：
     ① 查看日志页面的错误信息
     ② 验证 configs/commands.json 格式是否正确
     ③ 检查 MQTT 服务器是否收到消息

6. CSV 数据未保存
   ■ 检查项：
     • data 目录是否存在（程序会自动创建）
     • 磁盘空间是否充足
     • 是否有写入权限

   ■ 排查步骤：
     ① 查看日志是否有 CSV 写入错误
     ② 检查 data 目录权限
     ③ 手动创建 data 目录并重启程序

7. 历史数据查询无结果
   ■ 检查项：
     • 选择的日期范围内是否有数据
     • data 目录下是否存在对应日期的 CSV 文件
     • 选择的设备ID是否正确

   ■ 排查步骤：
     ① 检查 data 目录下的文件
     ② 用文本编辑器打开 CSV 文件查看内容
     ③ 确认文件编码为 UTF-8

==========================================
十三、性能优化建议
==========================================

1. 图表性能优化
   ■ 数据点数量：建议设置为 500-2000 点
     • 数据量大时降低点数可提高流畅度
     • 数据量小时增加点数可看到更多历史

   ■ 更新间隔：建议设置为 800-1500 毫秒
     • 高频数据可适当降低间隔
     • 低频数据可适当增加间隔

2. CSV 写入优化
   ■ 批量写入：
     • 自动每 5 秒或 100 条记录刷新一次
     • 大幅提升写入性能
     • 确保程序正常退出时所有数据被写入

3. 告警检测优化
   ■ 持续时长：建议设置 3-10 秒
     • 避免频繁误报
     • 降低告警检测的 CPU 占用

4. 日志优化
   ■ 定期清理：
     • 日志文件按天自动分割
     • 建议定期清理旧日志文件
     • 保留最近 30-90 天的日志即可
