# 设备自动发现功能测试指南

## 心跳订阅Topic

系统会自动订阅以下Topic来接收设备心跳：

```
iot/devices/heartbeat
```

**注意**：这个Topic由系统自动订阅，你不需要手动订阅它。只要连接MQTT服务器并启用设备自动发现功能，系统就会监听这个Topic。

## 使用 Python 脚本测试

创建一个Python脚本来模拟设备发送心跳和数据：

```python
import paho.mqtt.client as mqtt
import json
import time
import random

# MQTT 配置
BROKER = "119.45.181.86"
PORT = 1883
USERNAME = "admin"
PASSWORD = "your_strong_password"  # 请替换为实际密码

# 设备列表
devices = [
    {
        "deviceId": "ENV-001",
        "dataTopic": "iot/devices/ENV-001/datas",
        "deviceName": "会议室环境监测",
        "deviceType": "环境监测",
        "sensors": ["temperature", "humidity", "co2"]
    },
    {
        "deviceId": "TH-2024-001",
        "dataTopic": "iot/devices/TH-2024-001/datas",
        "deviceName": "仓库温湿度传感器",
        "deviceType": "温湿度传感器",
        "sensors": ["temperature", "humidity"]
    },
    {
        "deviceId": "METER-1001",
        "dataTopic": "iot/devices/METER-1001/datas",
        "deviceName": "A栋电表",
        "deviceType": "智能电表",
        "sensors": ["voltage", "current", "power"]
    }
]

def on_connect(client, userdata, flags, rc):
    if rc == 0:
        print("✓ 已连接到MQTT服务器")
    else:
        print(f"✗ 连接失败，返回码: {rc}")

def send_heartbeat(client, device):
    """发送设备心跳"""
    heartbeat = {
        "deviceId": device["deviceId"],
        "dataTopic": device["dataTopic"],
        "deviceName": device["deviceName"],
        "deviceType": device["deviceType"],
        "timestamp": int(time.time() * 1000)
    }

    topic = "iot/devices/heartbeat"
    payload = json.dumps(heartbeat)
    client.publish(topic, payload)
    print(f"📡 心跳已发送: {device['deviceId']} - {device['deviceName']}")

def send_sensor_data(client, device):
    """发送传感器数据"""
    payload_data = []

    # 根据设备类型生成不同的数据
    if "temperature" in device["sensors"]:
        payload_data.append({
            "name": "temperature",
            "value": round(random.uniform(18.0, 28.0), 1),
            "unit": "°C"
        })

    if "humidity" in device["sensors"]:
        payload_data.append({
            "name": "humidity",
            "value": round(random.uniform(40.0, 80.0), 1),
            "unit": "%"
        })

    if "co2" in device["sensors"]:
        payload_data.append({
            "name": "co2",
            "value": round(random.uniform(400.0, 800.0), 0),
            "unit": "ppm"
        })

    if "voltage" in device["sensors"]:
        payload_data.append({
            "name": "voltage",
            "value": round(random.uniform(215.0, 225.0), 1),
            "unit": "V"
        })

    if "current" in device["sensors"]:
        payload_data.append({
            "name": "current",
            "value": round(random.uniform(10.0, 20.0), 1),
            "unit": "A"
        })

    if "power" in device["sensors"]:
        payload_data.append({
            "name": "power",
            "value": round(random.uniform(2000.0, 4000.0), 0),
            "unit": "W"
        })

    data = {
        "deviceId": device["deviceId"],
        "timestamp": int(time.time() * 1000),
        "payload": payload_data
    }

    topic = device["dataTopic"]
    payload = json.dumps(data)
    client.publish(topic, payload)
    print(f"📊 数据已发送: {device['deviceId']} - {len(payload_data)} 个测点")

def main():
    print("=" * 60)
    print("设备自动发现功能测试脚本")
    print("=" * 60)

    # 创建MQTT客户端
    client = mqtt.Client(client_id="test_device_simulator")
    client.username_pw_set(USERNAME, PASSWORD)
    client.on_connect = on_connect

    # 连接到服务器
    print(f"\n正在连接到 {BROKER}:{PORT}...")
    client.connect(BROKER, PORT, 60)
    client.loop_start()

    time.sleep(2)  # 等待连接建立

    print(f"\n将模拟 {len(devices)} 个设备")
    print("心跳间隔: 30秒")
    print("数据发送间隔: 5秒")
    print("\n按 Ctrl+C 停止\n")

    # 首次发送所有设备的心跳
    print(">>> 发送初始心跳...")
    for device in devices:
        send_heartbeat(client, device)

    time.sleep(2)

    try:
        heartbeat_counter = 0
        data_counter = 0

        while True:
            # 每5秒发送一次数据
            data_counter += 1
            print(f"\n>>> 第 {data_counter} 轮数据发送")
            for device in devices:
                send_sensor_data(client, device)
                time.sleep(0.5)  # 避免同时发送

            # 每30秒发送一次心跳
            if data_counter % 6 == 0:  # 5秒 * 6 = 30秒
                heartbeat_counter += 1
                print(f"\n>>> 第 {heartbeat_counter} 轮心跳发送")
                for device in devices:
                    send_heartbeat(client, device)
                    time.sleep(0.5)

            time.sleep(5)  # 等待5秒

    except KeyboardInterrupt:
        print("\n\n正在停止...")
        client.loop_stop()
        client.disconnect()
        print("✓ 已断开连接")

if __name__ == "__main__":
    main()
```

## 使用 MQTT.fx 或 MQTTX 手动测试

### 步骤1：发送心跳消息

1. 打开MQTT客户端工具（MQTTX推荐）
2. 连接到服务器 `119.45.181.86:1883`
3. 使用用户名 `admin` 和密码
4. 发布消息到 **Topic**: `iot/devices/heartbeat`
5. 使用上面任意一个心跳JSON示例作为消息内容

### 步骤2：观察设备列表

1. 在MQTT Monitor中点击菜单 **设备(D)** -> **设备管理(M)**
2. 你应该能看到刚刚发送心跳的设备出现在列表中
3. 设备状态应该显示为"在线"（绿色）

### 步骤3：发送设备数据

1. 使用MQTT客户端发布数据到设备的数据Topic
2. 例如：发送到 `iot/devices/ENV-001/datas`
3. 使用对应的数据消息JSON
4. 数据应该会在MQTT Monitor的图表和表格中显示

### 步骤4：测试离线检测

1. 停止发送心跳消息
2. 等待60秒（默认超时时间）
3. 设备应该被标记为"离线"（红色）

## 测试清单

- [ ] 连接MQTT服务器成功
- [ ] 发送单个设备心跳消息
- [ ] 设备出现在设备管理列表中
- [ ] 设备显示为"在线"状态
- [ ] 发送多个设备心跳消息
- [ ] 所有设备都出现在列表中
- [ ] 发送设备数据到对应Topic
- [ ] 数据在图表/表格中正确显示
- [ ] 停止发送心跳60秒后设备标记为离线
- [ ] 恢复发送心跳后设备重新上线

## 注意事项

1. **心跳间隔**：建议每20-30秒发送一次心跳，确保在60秒超时前设备不会离线
2. **时间戳格式**：timestamp使用Unix毫秒级时间戳（例如：`Date.now()` 在JavaScript中，或 `int(time.time() * 1000)` 在Python中）
3. **deviceId唯一性**：每个设备的deviceId必须唯一
4. **dataTopic格式**：建议遵循 `iot/devices/{deviceId}/datas` 的格式

## 故障排查

### 设备没有出现在列表中

1. 检查心跳Topic是否正确：`iot/devices/heartbeat`
2. 检查JSON格式是否正确（必须包含 `deviceId` 和 `dataTopic`）
3. 查看MQTT Monitor的日志标签页，确认是否收到心跳消息
4. 确认 `EnableDeviceDiscovery` 在config.json中设置为 `true`

### 设备显示离线

1. 检查是否持续发送心跳（间隔应小于60秒）
2. 查看"最后心跳时间"，确认最近一次心跳时间
3. 确认网络连接正常

### 数据没有显示

1. 确认设备已经出现在设备列表中
2. 检查数据Topic是否与心跳中的 `dataTopic` 一致
3. 检查数据JSON格式是否符合规范
4. 查看日志标签页的错误信息
